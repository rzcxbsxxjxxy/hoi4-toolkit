载入顺序

① 工作台挂载序 = 当前 mods 数组顺序（近似展示）； ② 依赖修正后的游戏内加载序 = dependencies 拓扑序（被依赖的在前）。 两行不一致，即代表 dependencies 改写了默认按用户 .mod 文件名排序的结果。
求值序 ≠ 载入序：加载序在「求值」阶段不起决定作用——游戏通常按文件 ASCII 字符 ID 顺序求值。 各域口径不同：states 类先创建者胜（原版 123-ABC.txt 胜模组 123-XYZ.txt）； sprite 类后求值者胜；国策（focus）重复会破坏前置行生成，应避免。本工具按载入序近似判定，仅作参考。

依赖关系

replace_path 缺口

模组声明 replace_path 相当于替换该文件夹内【直接】文件（子文件夹不受影响）；声明了却没提供的直接文件，在游戏里就是不存在。
双 descriptor 注意：每个模组同时有 descriptor.mod（模组目录内，共享信息）与用户目录下的 .mod（含 path=）。 replace_path 必须两处都写——launcher 只删不抄，不会把 descriptor.mod 里的 replace_path 复制到用户 .mod。
